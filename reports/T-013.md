# T-013 게임 규칙 1단계 (중력·점프·발판)
- 담당: 서브에이전트 (worktree, sonnet)
- 한 일:
  - `src/core/game.ts`를 플랫포머 규칙으로 교체. Input = left/right/jump. 상수 MOVE_SPEED 240, GRAVITY 1800, JUMP_SPEED 650, MAX_FALL_SPEED 900 export.
  - player에 vy, onGround 추가. GameState에 platforms 추가. 레벨 = 바닥(높이 40) + 떠 있는 발판 3개(120,330 / 340,250 / 580,330, 각 140x20). 점프 최고 높이 약 117px라 발판 간 높이차 80px는 올라갈 수 있다.
  - update는 dt를 1/60초 이하 조각으로 나눠 반복. 한 조각: 가로 이동 → 가로 충돌 → 점프/중력(낙하 속도 제한) → 세로 이동 → 세로 충돌(착지/머리 부딪힘) → 좌우 경계.
  - `src/ui/main.ts`: 입력 매핑(좌우, ↑/W/Space 점프), 발판 그리기, 안내 문구 변경.
  - 테스트를 새 규칙에 맞게 13개로 재작성.
- 바뀐 파일: src/core/game.ts, tests/core/game.test.ts, src/ui/main.ts, reports/T-013.md
- 검증:
  - 준비 1번 `git merge --ff-only claude/vibrant-archimedes-t0utvy`: 성공 (첫 줄 "Updating c258700..da3c140", Fast-forward).
  - `npm ci`: 성공.
  - `npm test`: 13개 통과 (1 파일). 처음에 테스트 3개가 실패했는데, 테스트 시작 x좌표가 가운데 발판 위여서 생긴 테스트 쪽 실수였고 테스트를 고쳐서 해결했다 (게임 코드 문제 아님).
  - `npm run build`: 성공.
  - 브라우저에서 직접 실행해 보지는 않았다 (화면 확인은 안 함).
- 남은 일 / 위험:
  - 점프 키를 누르고 있으면 착지 즉시 다시 점프한다(연속 점프). 필요하면 후속 작업에서 "누른 순간만" 처리.
