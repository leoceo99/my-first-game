작업 전 읽기: CLAUDE.md, jarvis/LESSONS.md, docs/09_검술체계_조사.md, game/data/combat/, jarvis/handoff/T-107.md.

원칙
- 검술 동작은 팀이 직접 만든다(CLAUDE.md 8장). 실제 검술서의 원리·자세를 기준으로 한다.
- 동작은 데이터 파일로, 공통 뼈대 하나에 만든다.
- 디렉터가 보는 3인칭 뒷모습과 옆모습으로 연속 캡처해 확인한다.
- 기획 방향을 바꾸는 결정, 비용이 드는 일, 외부 공개는 하지 않고 자비스에게 올린다.
- 맡은 파일 범위 밖은 고치지 않는다. 끝나면 `jarvis/handoff/작업ID.md`에 인수인계를 쓴다.

완료 기준: 동작별 연속 캡처, 자동 테스트(타격 판정) 통과. 실제로 확인하지 않은 것을 "완료"라고 하지 않는다.
