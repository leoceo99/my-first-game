## 2026-11-12 · 첫 시작
- **디렉터의 의도보다 앞서 나감**: 첫 요청에 바로 게임(강철의 대지)을 만들었으나, 디렉터는 "계획 먼저"를 원했음.
  → 큰 작업은 반드시 계획 → 질문 → 승인 → 실행 순서로 한다.
- **언어**: 디렉터는 모든 소통을 한국어로 원함. 영어 보고 금지.
- **테스트 함정**: 자동 테스트에서 카메라가 지도 가장자리에서 고정되는 것을 빼먹어 "탭 선택 실패"로 오인함.
  → 화면 좌표 테스트는 실제 카메라 상태를 다시 읽어서 계산한다.
- **아이콘 생성 함정**: 같은 브라우저 페이지에서 크기를 바꿔 반복 렌더링하면 빈 이미지가 나옴.
  → 이미지 생성은 매번 새 페이지에서 한다. 생성 후 파일 크기·내용을 직접 확인한다.
- **로컬 서버**: 백그라운드 서버는 시간 제한으로 종료됨. 테스트 직전에 다시 켠다.

## 2026-11-12 · 두 번째 회의
- **디렉터는 "구체성"을 원함**: 팀 구성을 역할 이름만 적었더니 인원·성향·공유 방식까지 요청받음.
  → 계획은 "누가, 몇 명, 어떤 성향, 무엇을 어디에 남기는지"까지 쓴다.
- **디렉터의 강한 희망(주관식)은 비용·기술 제약과 함께 정직하게 보고**: 가능 여부, 필요한 것, 비용 추정, 추천을 한 번에 제시하고 결정은 디렉터에게.
- **시스템과 세계관을 엮으면 설계가 단단해짐**: 목숨 3번·새 게임·NPC 변화를 "되감기" 설정으로 설명하는 안이 나옴. 앞으로도 시스템마다 세계관상 이유를 찾는다.

## 2026-11-13 · 첫 야간 작업 실패
- **예약 작업이 푸시하지 못함**: 새 세션 방식의 예약에 저장소가 연결되지 않아 결과(T-005)가 사라짐.
  → 저장소를 연결한 전용 세션을 만들고, 예약을 그 세션으로 보내도록 바꿈. **예약을 만든 뒤에는 첫 실행 결과를 반드시 확인한다.**
- **디렉터의 아이디어가 기존 작품과 겹칠 때**: 대학살로 신을 부르는 줄거리가 유명 작품과 비슷했음. 숨기지 말고 바로 알리고 차별화 방안을 제시한다.
- **기존 자비스 체계 발견**: 다른 대화에서 만든 정기 브리핑·상황판이 이미 있었음. 새로 만들기 전에 예약 작업 목록을 먼저 확인한다.
- **자비스 혼자 '모순 해결'이라 판단하면 과신하게 됨**: v0.3에서 "정확히 맞는다"고 쓴 부분을 비평가가 기획서와의 충돌로 반려함. → 세계관 문서는 반드시 비평가 검토 후 디렉터에게 올린다.

## 2026-11-13 · 영어로 답한 실수 (중요)
- **두 번이나 영어로 보고함.** 디렉터가 번역하느라 힘들었다고 지적. 규칙 1번 위반.
  → 모든 답변·보고·문서는 한국어. 답을 보내기 전에 언어부터 확인한다. CLAUDE.md 2장 1번에 "영어로 답하지 않는다"를 명시함.
- **예약 작업의 지시문은 그 예약이 깨우는 대화에서만 바꿀 수 있다.** 다른 대화에서 바꾸려면 실패한다.
  → 지시문 본문은 저장소 파일(NIGHTLY.md, briefing.md)에 두고, 예약에는 "그 파일을 읽어라"만 적는다. 이러면 파일만 고쳐서 동작을 바꿀 수 있다.
- **오상 회의 첫 실전(11-13)**: 5인 병렬 호출 약 20초, 위원당 약 8만 토큰(대부분 문서 읽기). 의견이 독립적으로 나왔는데도 핵심(1+2 공통, 역봉인 제외)이 일치했고, 각자 다른 위험(조합 폭발, 감정, 유사성, 작업량, 규칙 충돌)을 찾음 → 3급 회의는 효과 있음. 비용을 줄이려면 안건 문서에 필요한 설정을 요약해 넣어 위원이 읽을 양을 줄인다.
- **(재발) 11-13 또 영어로 보고함.** 세 번째 지적. 원인: 긴 작업 뒤 보고를 쓸 때 언어를 확인하지 않음. → **보고를 쓰기 직전에 '이 글이 한국어인가'를 반드시 확인한다.** 모델이 바뀌어도(Sonnet/Opus) 같은 규칙.

## 2026-11-13 · 디렉터가 붙여 준 웹소설 연구
- 디렉터가 원문을 직접 붙여 주면 읽고 **기법만** 정리한다(`docs/11`). 원문은 저장소에 저장하지 않는다.
- 배운 핵심: 화자가 부정하는 문장이 진실의 표지판 / 권한이 오르면 정보가 열린다 / 이상한 장면 먼저, 설명은 나중 / 반전은 앞 장면을 다시 읽게 만들어야 한다.
- 서브에이전트가 5시간 한도에 걸리면 같은 에이전트를 SendMessage로 이어 간다(새로 만들지 않는다).

## 2026-11-17 · 야간 작업 (T-005 개발 기반)
- **화면 테스트는 한 점이 아니라 넓게 본다**: 가운데 한 픽셀만 검사했더니 물체의 구멍이라 실패. → 그려졌는지 확인할 때는 화면 전체에서 배경과 다른 비율을 잰다.
- **미리 깔린 브라우저와 Playwright 판을 맞춘다**: `@playwright/test`를 환경의 판(1.63.0)으로 고정하면 브라우저를 새로 받지 않아도 된다.
- **예약 알림이 3일치 밀려 한꺼번에 도착함**: 세션이 재시작되는 동안 야간 작업이 돌지 않았다. → 밀린 알림은 1회만 처리하고, 보고서에 빠진 날짜를 적는다.
- (디렉터 확인) 야간 작업이 며칠 안 돈 원인은 **사용량 한도**였다. → 알림이 밀려 도착하면 먼저 사용량 한도를 의심하고, 작업을 작게 유지한다.
- (11-17) 야간 세션이 디렉터 답을 받고 **통합 브랜치에 직접 푸시**했다(규칙은 자기 브랜치만). 총괄 작업과 같은 시각에 겹쳐 충돌이 났다. 통합 운영 지침(NIGHTLY)에 "통합 브랜치에 직접 쓰지 않는다, 운영 일지도 자기 브랜치에" 재강조 → 총괄이 병합.
- **작업 환경 fps는 실제 성능이 아니다**: 그래픽 카드 없이 소프트웨어로 그려 15fps 안팎. → 성능 판정은 디렉터 기기 측정으로만 하고, 보고서에 "참고값"이라고 쓴다.
- (11-17) **디렉터는 3인칭 뒷모습으로 본다**: 다리 흔들기만으로는 뒤에서 걷는 느낌이 안 남. 좌우 체중 이동·골반 기울기가 핵심. → 동작을 만들면 **디렉터가 보는 카메라 각도로** 연속 캡처해서 확인한다.
- (11-17) 발소리는 "실제 이동 거리"로 세야 발이 미끄러져 보이지 않고 벽에 붙어 달릴 때 소리가 나지 않는다.

## 2026-11-18 · 눈+손 통합 첫 야간 실행
- `get_session()` 응답에 `rate_limit_info`가 없을 수 있다. → 사용량 "알 수 없음"으로 적고 작업을 작게, 스토리 방은 쉰다(지침의 `allowed` 조건을 확인할 수 없으므로).
- 전날 야간 결과가 아직 병합되지 않았으면 새 작업 브랜치에 먼저 합쳐 둔다. 그래야 다음 결과가 옛 결과를 덮어쓰거나 충돌하지 않는다.
- (11-18) 통합 야간 첫 실행: 세션 조회는 야간 세션에서도 된다. 상황판 DB 쓰기는 자동 권한 모드에서 거부됐다 → 우회하지 않고 디렉터에게 알린다. 사용량 필드 위치는 지침에 정확히 적는다.
- (11-18) 할 말이 없을 때 영어 한 줄("No response requested.")을 남겨 디렉터가 또 혼란스러워했다. **어떤 경우에도 영어 문장을 디렉터 화면에 남기지 않는다.** 할 말이 없으면 한국어로 "진행 중, 결과 나오면 알림" 한 줄. 보고는 전문용어 없이 쉬운 말로.
- (11-18) 디렉터 운영 지시: 한도가 풀리면 바로 이어서 시작한다. **큰 결정은 묻고, 늘 돌아가야 하는 자잘한 일(검토·정리·중간 저장·모순 고치기)은 묻지 않고 진행한다.** 5시간 한도는 처음 뜬 뒤 5시간이면 풀린다.

## 2026-11-19 · 디렉터 혼란 (중요)
- **세션이 둘(총괄·야간)로 따로 보고하니 디렉터가 진행 상황을 전혀 모르겠다고 함.** → 대화 창구를 「자비스 총괄」 하나로 통일. 다른 세션 결과는 총괄이 모아 보고한다. 세션 이름은 역할이 바로 보이게 짓는다.
- **영어 보고 재발에 디렉터가 강하게 경고**("영어로 말하면 역할을 맞바꾸겠다"). → 규칙만으로는 부족해 설정으로 고정(`.claude/settings.json` language + 매 메시지 한국어 알림 훅).
- 디렉터 방향 전환(그래픽: 만화풍 → 사실적)은 결정 기록을 먼저 쓰고, 영향(성능·캐릭터·동작)을 솔직하게 같이 적은 뒤 관련 문서를 모두 고친다.
- (11-19) 총괄이 또 디렉터 화면에 영어 한 줄("No response requested.")을 남겼다. 디렉터 경고(영어가 또 나오면 총괄·야간 역할 교대). **할 말이 없을 때도 반드시 한국어 한 줄로 쓴다: "진행 중입니다. 결과가 나오면 알려 드리겠습니다."**
- (11-19) 옛 총괄은 한국어 설정을 넣은 뒤에도 영어로 답했다(설정 전에 시작된 세션이라 반영이 안 됨). → 새 세션은 `append_system_prompt`에도 한국어 규칙을 넣어 만든다. 설정 변경은 **새로 시작한 세션부터** 확실히 먹는다.
