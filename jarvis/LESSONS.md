## 2026-11-12 · 첫 시작
- **디렉터의 의도보다 앞서 나감**: 첫 요청에 바로 게임(강철의 대지)을 만들었으나, 디렉터는 "계획 먼저"를 원했음.
  → 큰 작업은 반드시 계획 → 질문 → 승인 → 실행 순서로 한다.
- **언어**: 디렉터는 모든 소통을 한국어로 원함. 영어 보고 금지.
- **테스트 함정**: 자동 테스트에서 카메라가 지도 가장자리에서 고정되는 것을 빼먹어 "탭 선택 실패"로 오인함.
  → 화면 좌표 테스트는 실제 카메라 상태를 다시 읽어서 계산한다.
- **아이콘 생성 함정**: 같은 브라우저 페이지에서 크기를 바꿔 반복 렌더링하면 빈 이미지가 나옴.
  → 이미지 생성은 매번 새 페이지에서 한다. 생성 후 파일 크기·내용을 직접 확인한다.
- **로컬 서버**: 백그라운드 서버는 시간 제한으로 종료됨. 테스트 직전에 다시 켠다.

## 2026-11-12 · 두 번째 회의
- **디렉터는 "구체성"을 원함**: 팀 구성을 역할 이름만 적었더니 인원·성향·공유 방식까지 요청받음.
  → 계획은 "누가, 몇 명, 어떤 성향, 무엇을 어디에 남기는지"까지 쓴다.
- **디렉터의 강한 희망(주관식)은 비용·기술 제약과 함께 정직하게 보고**: 가능 여부, 필요한 것, 비용 추정, 추천을 한 번에 제시하고 결정은 디렉터에게.
- **시스템과 세계관을 엮으면 설계가 단단해짐**: 목숨 3번·새 게임·NPC 변화를 "되감기" 설정으로 설명하는 안이 나옴. 앞으로도 시스템마다 세계관상 이유를 찾는다.

## 2026-11-13 · 첫 야간 작업 실패
- **예약 작업이 푸시하지 못함**: 새 세션 방식의 예약에 저장소가 연결되지 않아 결과(T-005)가 사라짐.
  → 저장소를 연결한 전용 세션을 만들고, 예약을 그 세션으로 보내도록 바꿈. **예약을 만든 뒤에는 첫 실행 결과를 반드시 확인한다.**
- **디렉터의 아이디어가 기존 작품과 겹칠 때**: 대학살로 신을 부르는 줄거리가 유명 작품과 비슷했음. 숨기지 말고 바로 알리고 차별화 방안을 제시한다.
- **기존 자비스 체계 발견**: 다른 대화에서 만든 정기 브리핑·상황판이 이미 있었음. 새로 만들기 전에 예약 작업 목록을 먼저 확인한다.
- **자비스 혼자 '모순 해결'이라 판단하면 과신하게 됨**: v0.3에서 "정확히 맞는다"고 쓴 부분을 비평가가 기획서와의 충돌로 반려함. → 세계관 문서는 반드시 비평가 검토 후 디렉터에게 올린다.
