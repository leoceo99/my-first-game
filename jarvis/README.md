# 자비스 구조도

> 자비스 = 디렉터의 **모든 Claude 세션을 관리하는 비서** + **게임 개발 스튜디오의 총괄 PD**
> v1(11-07~10, 세션 관리)과 v2(11-12~, 게임 스튜디오)를 11-13에 통합했다.

## 1. 자비스의 몸

| 부분 | 하는 일 | 실체 | 문서 |
|---|---|---|---|
| **두뇌** (총괄) | 디렉터와 대화, 계획, 일 맡기기, 검수, 보고 | 총괄 세션 1개 (지금: 이 대화) | `CLAUDE.md`, `TODO.md`, `jarvis/commands.md` |
| **회의** (오상 회의) | 중요한 결정을 다섯 인격이 토의 | 위원 에이전트 5 | `jarvis/COUNCIL.md` |
| **눈** (정기 브리핑) | 8시간마다 모든 세션·예약·사용량 점검 → 상황판 갱신 → 중요하면 알림 | 브리핑 전용 세션 + 예약 | `jarvis/briefing.md` |
| **화면** (상황판) | 세션 상태, 확인할 일, 결정 대기를 링크 하나로 | Artifact 페이지 + DB | `jarvis/dashboard/` |
| **밤의 손** (야간 작업) | 매일 새벽 승인된 게임 작업 1개 진행 | 야간 전용 세션 + 예약 | `jarvis/NIGHTLY.md` |
| **손** (개발팀) | 실제 작업 | 팀원 에이전트 12, 작업 세션 | `docs/07_팀_운영_상세.md` |
| **성장** | 실수 기록, 규칙 갱신, 도구·테스트 축적, 개선 제안 | 회고 기록, 역량 점검표 | `jarvis/LESSONS.md`, `jarvis/CAPABILITIES.md` |

## 2. 문서 지도
| 파일 | 내용 | 누가 고치나 |
|---|---|---|
| `CLAUDE.md` | 모든 세션 공통 규칙 | 총괄 |
| `TODO.md` | 자비스 운영 현황: 결정 대기, 세션 등록부, 결정 기록 | 총괄 |
| `jarvis/TASKS.md` | 게임 개발 할 일 | 총괄 (야간 작업은 상태만) |
| `jarvis/commands.md` | 디렉터가 하는 말 → 자비스가 하는 일 | 총괄 |
| `jarvis/meetings/` | 회의록 | 의장 |
| `jarvis/reports/`, `reports/` | 작업 보고 | 각 작업자 |
| `jarvis/handoff/` | 인수인계 노트 | 각 작업자 |
| `docs/` | 기획 문서 (정답) | 총괄·팀 |

## 3. 하루의 흐름
```
새벽 02:52 (한국)  밤의 손: 승인된 게임 작업 1개 → 보고서
8시간마다           눈: 세션·예약·사용량 점검 → 상황판 → 중요하면 알림
디렉터가 말할 때     두뇌: 대화 → (중요하면 회의) → 팀에 배분 → 검수 → 보고
작업이 끝날 때       성장: 교훈 기록 → 반복되면 규칙으로
```
