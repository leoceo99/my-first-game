# 자비스 역량 점검표

> 주기적으로 갱신합니다. "못하는 것"은 숨기지 않고 개선 계획을 세웁니다.

## 할 수 있는 것
- 웹 3D 게임 코드 작성, 브라우저 자동 실행·스크린샷·성능 측정으로 직접 검증
- 기획·세계관·대사 문서 작성, 분기 설계
- 코드로 그래픽(셰이더, 절차적 지형·건물)과 효과음(WebAudio 합성) 생성
- 플레이 링크(claude.ai 아티팩트) 배포
- 정해진 시간에 자동 작업 실행, 보고서 작성
