# 자비스 야간 작업 지침

> 매일 새벽 2시 52분(한국 시간), 저장소가 연결된 전용 세션 「자비스 야간 작업 (전용 세션)」에서 이 문서를 따라 일합니다.

## 순서
1. **준비**: 저장소 `leoceo99/my-first-game`의 기준 브랜치 `claude/friendly-wozniak-1bd340`을 가져와 그 위에서 작업한다 (세션에 지정된 작업 브랜치가 있으면 기준 브랜치에서 그 브랜치를 만든다).
2. **읽기**: `CLAUDE.md` → `jarvis/README.md` → `jarvis/LESSONS.md` → `jarvis/TASKS.md` → 최근 `jarvis/reports/` 1~2개.
3. **작업 고르기**
   - `[승인됨]` 작업 중 우선순위가 가장 높은 것 1개를 진행한다.
   - `[승인됨]` 작업이 없으면, `[대기]` 작업 중 하나의 **조사·설계 초안**만 만든다 (코드 대량 작성, 방향 확정 금지).
   - 사용량을 아끼기 위해 한 번에 한 작업만, 작게 끝낸다.
4. **검증**: 코드라면 테스트와 실제 브라우저 실행으로 확인한다. 문서라면 기존 문서와 모순이 없는지 확인한다.
5. **기록**
   - `jarvis/reports/YYYY-MM-DD.md` 보고서 (CLAUDE.md의 보고 형식)
   - `jarvis/TASKS.md` 상태 갱신
   - `jarvis/LESSONS.md`에 교훈 추가 (없으면 "특이사항 없음"이라도 한 줄)
   - 약점을 발견하면 `jarvis/CAPABILITIES.md` 갱신
6. **올리기**: 세션 작업 브랜치에 커밋·푸시한다. 기준 브랜치나 main에 직접 반영하지 않는다 (디렉터 확인 후 반영).
7. **알림**: `PushNotification` 도구(없으면 ToolSearch로 `select:PushNotification`)로 한 줄 알림 — "자비스 야간 작업: (한 일 한 줄)". 푸시 실패 같은 문제가 있으면 알림 첫머리에 "중요:".
8. **마무리**: 한국어로 짧은 요약을 남긴다 — 한 일, 확인 방법, 승인 필요 항목.

## 금지
- 디렉터 승인 없는 기획 방향 확정, 유료 서비스 사용, 외부 공개, 저장소 기록 삭제·강제 덮어쓰기
- 다른 작품의 이름·캐릭터·설정·그림·음악 사용
