## 핵심 발견
1. 필수 수정 12건, 권고 12건. 해석표에 계열 기본 반응 칸이 없고, 장면 전용 의도를 선언할 칸이 없고, 4계열 결과(FAMILY_OK/FAIL)·겉말/속뜻 판정을 적을 자리가 없었다. 조건식 규칙이 "함수 호출 없음"과 예시 `trust()`와 충돌했다.
2. 4계열 뜻풀이가 60개 의도와 어긋났다 → 계열 수는 두고 뜻을 넓혔다. 일상 의도 4개(인사·감사·농담·작별)는 기록에서 제외하는 안. "한 글자 입력 = 침묵"은 "네/응" 오판이라 고쳤다.
3. 인물 카드 전용 의도 18줄 중 12가지가 사전과 어긋났다(예: `appeal_faith` ↔ `invoke_faith`, "시기" → 장면 전용 `scene:envy`, "회유" → `bargain` 합침, `give_up` 추가, `ask_where`+`ask_when` 합침). 별칭표를 13의 8절에 만들었다. **인물 카드 파일은 고치지 않았다 → 스토리팀이 카드·양식 이름을 맞춘다.**
4. 크기 어림 오류: 장면당 4~8KB는 4~8배 작았다. 다시 계산하면 장면당 약 30~40KB, 장면 3,000개에 문장 24만~30만 개(계산값, 실측 아님).
