# T-004 인수인계 · 기술 검증 프로토타입
- 담당: 자비스(직접 수행) · 검토자(예정): qa-tester(조작감·성능), art-sound-director(셀 셰이딩 느낌)
- 플레이: https://claude.ai/artifact/ByKniSjHG64kQtwTSMYHQz (비공개)
- 구조
  - `src/sim/player.ts` 이동 규칙(걷기 2.2m/s·달리기 5m/s, 대각선 보정, 집·나무·우물 충돌, 세계 경계 80m) — 화면과 분리, 단위 테스트 7개
  - `src/sim/save.ts` 저장 형식 v2 + v1 변환기(변환기 구조 시험용) — 단위 테스트 3개
  - `src/engine/` 마을(world), 임시 주인공(character), 1·3인칭 카메라(camera, 0.25초 부드러운 전환), 입력(input: 키보드·마우스·터치)
  - 셀 셰이딩 = 3단 명암 재질 + 뒤집은 껍데기 외곽선 (`engine/toon.ts`)
  - 저장은 브라우저 저장소(localStorage), 막히면 메모리 임시 보관 + 안내 문구. IndexedDB·여러 슬롯·파일 내보내기는 아직 안 함(docs/03 2장).
- 성능: 작업 환경(그래픽 카드 없음, 소프트웨어 렌더링)에서 14~19fps. 실제 노트북 수치 아님. 그림자 해상도 1024, 화면 배율 상한 1.5.
- 한계: Rapier 물리 미사용(평면 충돌만), 3인칭 카메라가 벽 뒤로 들어가면 가려짐(카메라 충돌 없음), 지형 높낮이 없음.
- 다음: T-107(롱소드 베기 3종)은 `engine/character.ts`의 임시 주인공 위에 얹을 수 있음.
