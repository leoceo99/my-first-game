- 구현한 칸: byFamily(4계열 기본) + byIntent(예외) · replies(의도별 첫 반응) · **familyReplies(계열 기본 반응 — docs/12에 없어 새로 추가)** · unclear(첫 번째 되묻기, 두 번째 기본 갈 곳) · sceneIntents(장면 전용 의도, 예문은 `<장면ID>.intent_<id>`) · repeatAcrossLives(세 삶 반복 대사) · when 조건 · 효과 `set` / `trust() +=` / `add`.
- 시험 장면에서 볼 수 있는 것: 엉뚱한 말 → 되묻기 / 사실대로 → 신뢰 +1 → 다른 질문 / 끝에서 장로 비밀을 들으면 주인공 기억 생김 / **되감기(시험)** → 2번째 삶: 장로는 잊었지만 첫 대사가 바뀌고 장면 전용 의도 「아들 지목」이 열림 / 입력 칸에 쓰는 동안 조작 키 무시, 대화 중 이동 멈춤.

## 검사기 (`npm run check:dialogue`, `npm test`에도 포함)
- 오류: 식 문법, 장부에 없는 플래그(오타), 없는 인물, 없는 노드로 가기, 시작에서 갈 수 없는 노드, 끝에 못 닿음, go·ask·end 중복/없음, 계열 빠짐, 받지 않는 의도를 byIntent·replies·말 고르기에 씀, 장면 전용 의도 이름 겹침·대표 문장 없음, 문장 표에 없는 ID·맥락 메모 없음, 장부 값(enum 값·int 범위·bool·list에만 add), 세 삶 반복 대사 2줄 이상.
- 경고: 90자 넘는 대사, 같은 문장 여러 곳, 계열 기본 반응 없음, 안 쓰는 문장, 장면 전용 의도 예문 3개 미만, 다시 올 수 있는 노드인데 기본 반응 1줄.
- 지금 장면: **오류 0 · 경고 0**.
