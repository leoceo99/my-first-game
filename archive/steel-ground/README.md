# 강철의 대지 (STEEL GROUND)

아이패드에서 플레이하는 **실시간 전술 전쟁 게임**입니다. 설치 없이 브라우저(사파리)에서 바로 실행되고, 홈 화면에 추가하면 앱처럼 전체 화면으로 즐길 수 있습니다.

## 게임 소개

강을 사이에 두고 두 군대가 맞섭니다. **5개의 전략 거점**(A 농장 · B 마을 · C 다리 · D 교회 · E 공장)을 점령하세요.
거점을 더 많이 가진 쪽이 상대의 **티켓(전투력)** 을 깎습니다. 적 티켓이 0이 되면 승리합니다.

### 병과

| 부대 | 비용 | 특징 |
|---|---|---|
| 소총 분대 | 120 | 5명. 다목적 보병 |
| 기관총 팀 | 150 | 거치 후 사격. 적을 **제압**해 느리고 부정확하게 만듦 |
| 대전차 팀 | 170 | 로켓으로 전차 파괴 |
| 박격포 팀 | 200 | 장거리 곡사. 건물 너머 공격 가능, 최소 사거리 있음 |
| 중형 전차 | 400 | 주포 + 동축 기관총. **후면 장갑이 약함** |
| 포병 지원 | 300 | 원하는 지점에 포탄 10발 (재사용 50초) |

### 사실적인 전투 요소

- **엄폐**: 숲·모래주머니·건물 옆에 있는 보병은 총격 피해가 줄어듦
- **시야/전장의 안개**: 건물은 시야를 가리고, 숲 속 보병은 가까이 가야 보임
- **제압**: 집중 사격을 받은 보병은 엎드리고(▼), 느려지고, 명중률이 떨어짐
- **장갑 방향**: 전차는 정면이 단단하고 측면·후면이 약함
- 포탄 자국, 전차 궤도 자국, 불타는 잔해, 거리에 따라 먹먹해지는 입체 음향

## 조작법

**터치 (아이패드)**
- 아군 탭 → 분대 선택 (두 번 탭: 화면 안 같은 병과 전체 선택)
- 꾹 누른 뒤 드래그 → 범위 선택
- 땅 탭 → 이동 / 적 탭 → 집중 공격
- 한 손가락 드래그 → 지도 이동, 두 손가락 → 확대/축소
- 미니맵 탭 → 해당 위치로 이동

**키보드/마우스**: 좌클릭 선택 · 드래그 범위선택 · 우클릭 이동/공격 · WASD 화면이동 · 휠 확대 · 1~5 증원 · B 포격 · Space 일시정지

## 실행 방법

### 컴퓨터에서 테스트
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 아이패드에서 플레이 (GitHub Pages)
1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 게임이 있는 브랜치 / `/ (root)` 선택 후 Save
3. 잠시 뒤 표시되는 주소(`https://<아이디>.github.io/my-first-game/`)를 아이패드 사파리로 열기
4. 공유 버튼 → **홈 화면에 추가** → 앱처럼 전체 화면 실행

## 파일 구조

```
index.html            화면 구성 (HUD, 메뉴)
style.css             UI 디자인
js/main.js            입력(터치/마우스), HUD, 게임 루프
js/game.js            전투 시뮬레이션 (유닛, 사격, 탄도, 거점, 티켓)
js/map.js             지도 생성 (강, 도로, 마을, 숲) 과 길찾기(A*)
js/render.js          유닛·전장 그리기, 전장의 안개, 미니맵
js/fx.js              폭발, 연기, 예광탄 등 효과
js/audio.js           효과음 합성 (WebAudio, 외부 파일 없음)
js/ai.js              적 지휘관 AI
js/data.js            유닛 능력치 / 비용 (밸런스 조정은 여기서)
```

외부 라이브러리나 이미지 파일 없이 모든 그래픽과 사운드를 코드로 생성합니다.
