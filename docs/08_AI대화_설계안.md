# 08. AI 대화 설계안 — 주관식 답변과 살아 있는 NPC

> 디렉터 요청: 선택지 대신 **주관식으로 답하고**, NPC가 **같은 말을 반복하지 않고 계속 달라지게**.
> 결론: **지금 기술로 가능합니다.** 다만 인터넷 연결, 작은 서버, AI 사용 요금이 필요해서 디렉터 승인이 필요합니다.

## 1. 원리 — "뼈대는 작가가, 살은 AI가"

AI에게 이야기를 전부 맡기면 짜임새가 무너집니다. 그래서 역할을 나눕니다.

| 담당 | 맡는 것 |
|---|---|
| 작가팀 (미리 작성) | 진실, 사건, 분기, 엔딩 조건, NPC 인물 카드(성격·비밀·말투·아는 것), 꼭 들어가야 할 대사 |
| AI (실시간) | ① 플레이어가 쓴 답을 읽고 의도를 파악해 작가가 만든 분기 중 어디로 갈지 판단 ② 인물 카드와 현재 상황에 맞게 NPC의 말을 매번 새로 씀 |
| 게임 (규칙) | 관계 수치, 기억, 사건 진행, 엔딩 조건 검사 — AI가 규칙을 어기지 못하게 막음 |

**예시**
- 상황: 마을 장로가 "어젯밤 무엇을 보았나?"라고 묻는 장면 (작가가 분기 5개를 미리 설계: 진실을 말함 / 거짓말 / 숨김 / 협박 / 거래 제안)
- 플레이어 입력: "글쎄요, 술값이라도 주시면 기억이 날지도 모르겠네요"
- AI 판단: "거래 제안" 분기 + 말투는 "능청" → 관계 수치 변화는 게임 규칙이 적용
- NPC 응답: 장로의 인물 카드(인색함, 아들을 잃은 비밀)에 맞게 AI가 새로 쓴 대사

이 구조라면 **엔딩과 진실은 작가가 통제하면서**, 플레이어는 자유롭게 말하고 NPC는 매번 다르게 반응합니다.

## 2. NPC가 계속 달라지게 만드는 장치
1. **기억**: NPC는 플레이어와 나눈 대화의 요약, 약속, 거짓말을 기억합니다.
2. **관계와 감정 상태**: 신뢰·두려움·호감 수치에 따라 말투가 바뀝니다.
3. **세계 상황**: 계절, 전쟁, 소문, 최근 사건을 알고 반영합니다.
4. **아는 것의 제한**: 인물 카드에 "이 사람이 모르는 것"을 적어 AI가 아는 척하지 못하게 합니다.

## 3. 선택지와의 관계
- 기본은 **주관식 입력**입니다. 입력창 아래에 "말 고르기" 버튼을 둬서 원하면 7~10개 선택지를 볼 수도 있게 합니다.
- **인터넷이 없거나 AI 서버에 문제가 생기면** 자동으로 선택지 방식으로 바뀝니다. 그래서 작가팀은 모든 분기에 선택지 문장도 함께 씁니다.

## 4. 필요한 것과 비용

| 항목 | 내용 |
|---|---|
| AI | Anthropic의 Claude API |
| 서버 | 게임과 AI 사이를 잇는 작은 서버. **AI 사용 키를 게임 안에 넣으면 누구나 훔쳐 쓸 수 있기 때문에** 키는 서버에만 보관합니다. 개발 중에는 무료~저가 서버로 충분합니다 |
| 계정 | 디렉터 명의의 Anthropic 개발자 계정과 결제 수단 (사용한 만큼 청구) |

**요금 추정** (2026년 11월 기준 공식 단가로 계산한 대략치. 실제 값은 프로토타입에서 측정)
- 대화 한 번에 AI가 읽는 양 약 3,000 토큰(인물 카드 + 상황 + 최근 대화), 쓰는 양 약 200 토큰으로 가정합니다. 토큰은 AI가 글을 세는 단위로, 한국어 한 글자가 대략 1토큰 정도입니다.

| 모델 | 단가 (100만 토큰당 읽기/쓰기) | 대화 1회 | 1시간 플레이 (대화 60회 가정) |
|---|---|---|---|
| Claude Opus 5.5 (가장 똑똑한 기본 모델) | $4 / $20 | 약 $0.016 (약 20원) | 약 $1 (약 1,300원) |
| Claude Haiku 5.5 (가볍고 빠른 모델) | $0.10 / $0.50 | 약 $0.0004 (1원 미만) | 약 $0.02 (약 30원) |

- 반복되는 인물 카드는 **캐싱**(AI가 이미 읽은 내용을 재사용해 싸게 처리하는 기능)으로 더 줄일 수 있습니다.
- 어떤 모델을 쓸지는 비용과 품질이 걸린 문제라 **디렉터가 결정**합니다. 추천: 개발과 테스트는 Opus 5.5로 품질 기준을 잡고, 출시 전에 Haiku 5.5와 비교 시험을 해서 품질이 충분하면 바꿉니다.
- 출시 후에는 플레이어 수만큼 비용이 늘어나므로, 판매 방식(가격, 구독, 대화량 제한)도 그때 함께 정해야 합니다.

## 5. 위험과 대책

| 위험 | 대책 |
|---|---|
| AI가 설정에 없는 말을 지어냄 | 인물 카드의 "아는 것/모르는 것", 게임 규칙 검사, 품질 평가 테스트 |
| 플레이어가 AI를 엉뚱하게 조종하려 함 | 플레이어 입력은 "대사"로만 취급, 판단은 정해진 분기 중에서만 고르게 함 |
| 응답이 느림 | 짧은 응답, 스트리밍(글자가 생기는 대로 보여 주기), 생각하는 동안 NPC 몸짓 연출 |
| 다국어 | AI가 플레이어 언어로 바로 응답. 현지화 원칙의 말투 규칙을 인물 카드에 포함 |
| 비용 폭주 | 하루 사용량 한도, 서버에서 플레이어별 제한 |

## 6. 단계 계획
1. **0~1단계**: 대화 데이터 형식을 처음부터 "분기 + 인물 카드 + 선택지 문장" 구조로 설계 (AI 없이도 동작)
2. **2단계 (10분 튜토리얼)**: NPC 1~2명에게 AI 주관식 대화 시험 적용 → 품질·속도·비용 측정 보고
3. 측정 결과를 보고 확대 범위 결정
