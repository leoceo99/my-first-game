# 00. 비전과 레퍼런스

> 이 문서는 프로젝트의 **북극성**입니다. 모든 결정은 여기 적힌 방향과 맞는지 먼저 확인합니다.
> 상태: **초안 v0.1 — 디렉터(사용자) 승인 대기**

## 1. 한 줄 소개 (가칭)

**"한 사람의 인생으로 세계의 진실에 다가가는 중세 다크 판타지 3D RPG."**
플레이어는 어떻게 태어날지(신분·나이·성별·재력·직업·재능·특징)를 고르고, 그 삶을 직접 살아갑니다.
영주가 되면 군대를 이끌고, 용병이 되면 용병단을 이끌고, 농민이라면 맨손에서 시작합니다.
처음에는 서로 무관해 보이던 제국과 왕국들의 이야기가, 진실에 다가갈수록 하나로 엮입니다.

시리즈 구상: **1편 = 중세**. 이후 다른 시대로 이어지는 연작 (세계관과 진실은 시리즈 전체를 관통).

## 2. 디자인 기둥 (Pillars) — 모든 기능은 이 중 하나 이상을 강화해야 함

| # | 기둥 | 뜻 | 하지 않을 것 |
|---|---|---|---|
| 1 | **나만의 인생** | 출신과 선택에 따라 전혀 다른 삶·관계·엔딩 | 모두가 같은 길을 걷는 일직선 스토리 |
| 2 | **진실을 향한 여정** | 메인·서브·히든 스토리가 단서로 연결, 스스로 파헤침 | 설명으로 떠먹여 주는 진실 |
| 3 | **무게감 있는 전쟁** | 직접 싸우는 손맛 + 부대를 지휘하는 전략 | 가볍고 장난스러운 전투 |
| 4 | **살아 있는 세계** | 시간·계절·나이·경제·정치가 플레이어와 무관하게도 굴러감 | 플레이어만 기다리는 정지된 세계 |
| 5 | **질리지 않음** | 반복 플레이마다 새 출신, 새 진실 조각, 새 엔딩 | 한 번 하면 끝나는 콘텐츠 |

## 3. 목표 경험 (톤)

- **분위기**: 세계는 아름답지만, 그 밑의 진실은 상상도 못할 만큼 어둡다. 주인공은 그것을 막으려 한다.
- **희망의 크기**: 출신(오리진)마다 **해피엔딩은 단 하나**. 나머지는 배드엔딩 또는 열린 결말. → 해피엔딩은 "찾아내야 하는 보물".
- **연령**: 15~18세 (피 표현 있음, 내장 노출 등 극단적 고어는 없음). 옵션에서 잔혹 표현 단계 조절 가능.
- **그래픽**: 애니메이션풍 3D (셀 셰이딩 기반의 극화풍). 실사 수준 그래픽은 목표로 하지 않음 — 무게감은 연출·사운드·스토리로 만든다.

## 4. 레퍼런스 조사 (참고만 하며, 설정·캐릭터·장면을 가져오지 않음)

### 4-1. 웹툰 (11편)

| 작품 | 우리가 배울 점 |
|---|---|
| 배드 본 블러드 | 게임 IP(RF 온라인) 세계관을 이야기로 확장한 사례 — 우리도 시리즈 세계관을 처음부터 크게 설계 |
| 킬 더 드래곤 | 예언된 멸망(15년 후 침공)을 향한 카운트다운 구조 → "다가오는 파국"이 주는 긴장감 |
| 별을 품은 소드마스터 | 빈민가 고아의 밑바닥 출발, 검에 깃든 존재와의 대화 → 낮은 신분 출발의 서사적 재미 |
| 포크&나이프 | 중세 다크 판타지, 증오와 차별이 지배하는 세계 → 세계 자체의 잔혹함 |
| 환생했더니 대공의 셋째 아들 | 전직 용병단장이 귀족으로 → 신분 변화가 주는 플레이 변화 |
| 불멸낭인 | 긴 세월을 산 용병의 마지막 의뢰 → 용병 출신 루트의 감성 |
| 검술명가 막내아들 | 몰락한 가문 출신의 성장 → 가문·후계 시스템 |
| 전지적 독자 시점 | 세계의 규칙 자체에 숨은 진실, 시나리오 구조 → 진실 탐구형 메인 스토리 |
| 신의 탑 | 층마다 드러나는 비밀과 세력 구도 → 단계적 진실 공개 |
| 악역의 엔딩은 죽음뿐 | 선택지와 수많은 배드엔딩, 단 하나의 생존 루트 → **우리 엔딩 구조의 가장 가까운 참고** |
| 새벽을 얽매는 뱀 | 판타지 정치극 → 제국·왕국 간 권력 다툼 |

> 사용자가 말한 "회귀한 용병 ○○" 작품은 정확한 제목을 찾지 못했습니다. 제목을 알려주시면 추가로 분석하겠습니다.

### 4-2. 애니메이션 (12편)

| 작품 | 우리가 배울 점 |
|---|---|
| 진격의 거인 | 세계의 진실이 뒤집히는 충격, 복선 회수 → 메인 스토리 구조의 핵심 참고 |
| 강철의 연금술사 BROTHERHOOD | 연금술의 규칙(등가교환)과 대가 → **마법·연금술·주술 체계 설계 원칙**: 힘에는 반드시 규칙과 대가 |
| 베르세르크 (1997) | 용병단, 신분 상승의 야망, 배신 → 용병 루트와 비극의 무게 |
| 빈란드 사가 | 전쟁의 허무와 성장, 복수 → 성숙한 전쟁관 |
| 클레이모어 | 인간과 괴물의 경계, 조직의 숨은 목적 → 히든 스토리 |
| 메이드 인 어비스 | 귀여운 겉모습 속 잔혹한 진실 → "아름다운 세계, 어두운 진실" 톤 |
| 장송의 프리렌 | 긴 시간의 흐름, 늙음과 이별 → 나이·세월 시스템의 감성 |
| 아르슬란 전기 | 왕국 간 전쟁, 군대 지휘 → 영지전·전략 |
| 도로로 (2019) | 대가를 치르는 거래, 저주 → 주술 체계 |
| Re:제로부터 시작하는 이세계 생활 | 죽음과 반복 → **목숨 3번 시스템**의 긴장감 |
| 늑대와 향신료 | 중세 경제·상인의 삶 → 상인 루트, 살아 있는 경제 |
| 고블린 슬레이어 | 냉혹한 현실 묘사 수위 → 15~18세 수위의 기준선 |

### 4-3. 게임 장르 레퍼런스 (시스템 참고)
- **마운트 앤 블레이드 계열**: 직접 싸우면서 부대 지휘, 영지전 — 전투 기둥 참고
- **크루세이더 킹즈 계열**: 혈통·가문·정치·후계 — 인생/가문 시스템 참고
- **킹덤 컴 계열**: 중세 생활의 사실감, 신분이 낮은 주인공 — 생활 시스템 참고
- **디트로이트 비컴 휴먼 계열**: 갈래가 많은 선택과 결과 흐름도 — 분기 설계 참고
- **발로란트 / 오버워치 / 콜 오브 듀티**: (사용자 언급) 연출·타격감·완성도의 눈높이 참고
