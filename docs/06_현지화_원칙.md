# 06. 현지화(다국어) 원칙

> 목표: 번역이 아니라 **그 언어로 처음 쓴 것처럼** 느껴지게 한다.

## 1. 구조
- 모든 문장은 ID로 관리 (`story.prologue.elder_01`)
- 원문은 한국어. 각 문장에 **맥락 메모**를 붙임: 화자, 청자, 관계, 감정, 신분 차이, 말장난·복선 여부
- 용어집(`game/locales/glossary.md`): 고유명사, 칭호, 힘의 체계 용어 — 언어별 확정 번역과 이유

## 2. 번역 원칙
1. **말투는 신분과 관계를 반영**: 한국어 존댓말/반말 차이를 영어에서는 어휘·격식(thou/my lord 등)으로, 일본어에서는 경어 체계로 옮김
2. **복선 보존**: 나중에 의미가 뒤집히는 문장은 메모에 "복선"으로 표시하고, 두 가지로 읽히는 모호함을 유지
3. **고유명사 일관성**: 용어집 밖의 새 번역 금지
4. **길이 제한**: UI 문장은 언어별 최대 길이 검사
5. **문화 적응**: 속담·관용구는 직역하지 않고 같은 느낌의 표현으로 바꿈

## 3. 검수
- 현지화 담당 에이전트가 번역 → 다른 관점의 역번역 검사 → 용어집·길이 자동 검사
- 출시 전 원어민 검수 권장 (비용 발생 시 디렉터 승인)

## 4. 초기 지원 언어 (제안)
한국어(원문), 영어, 일본어 → 이후 중국어(간체·번체), 스페인어 등 확장
