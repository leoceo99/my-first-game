# 진실: 「되풀이되는 세계」 v0.5

> 상태: ✅ 디렉터 확정 / 🔧 자비스 보완(승인 필요) / ❓ 함께 정할 것
> 이전 판 v0.4의 확정 설정 1~12는 그대로 유효합니다. 이 판은 **11-13 디렉터 3·4차 결정**을 반영해 바뀐 부분만 정리합니다.

## 1. 바뀐 큰 그림
**대륙은 두 제국과 아홉 왕국이 두 진영으로 갈라져 30년 동안 싸운다. 한쪽은 "악마를 토벌하는 성전"이라 믿고, 다른 쪽은 "악마 숭배자"라는 누명을 쓴다. 그러나 진짜 악마를 섬기는 쪽은 성전을 외치는 쪽이며, 양쪽의 모든 죽음이 하나의 유물로 흘러간다.**

## 2. 세력과 전쟁 구도 ✅ (세부 🔧)
| 진영 | 구성 | 스스로 믿는 것 | 진실 |
|---|---|---|---|
| **성전 연합** | 제1제국(주범) + 왕국 4개 | 악마 숭배자를 토벌하는 정의로운 성전 | 제1제국 황제와 비밀 조직이 대악마에게 바치는 제사 |
| **낙인 진영** | 제2제국 + 왕국 5개 | 누명을 쓴 자들의 생존 전쟁 | 일부는 진짜로 **옛 신을 몰래 섬기고 있다**. 제국은 그것을 "악마 숭배"로 뒤집어씌웠다 |

- 🔧 **반전의 핵심**: 진짜 신을 섬기는 쪽이 악마 숭배자로 몰리고, 악마를 섬기는 쪽이 성전군이 된다.
- 🔧 **모두가 회색**: 낙인 진영의 제2제국도 결백하지 않다. 제2제국 황제는 누명을 핑계로 영토를 넓히려 하고, 칠대 마왕 레비아탄(질투)이 양쪽 왕들의 시기심을 부추겨 전쟁을 키운다.
- 🔧 **플레이어의 시선이 갈린다**: 출신 지역에 따라 성전 연합 쪽에서 시작하기도 하고, 낙인 진영 쪽에서 시작하기도 한다. 같은 전쟁이 완전히 다르게 보인다. (비평가가 지적한 "시점 다양성" 문제 해결)

### 누명을 씌우는 방법 🔧
1. 비밀 조직이 낙인 진영의 국경 마을에 하급 악마(잡귀)를 몰래 풀어 놓는다.
2. "악마가 그 땅에서 솟아났다"는 것을 증거로 내세운다.
3. 낙인 진영의 한 왕국에 실제로 옛 신 숭배가 남아 있다는 사실을 찾아내, 그것을 "악마 숭배"로 왜곡해 퍼뜨린다.

### 혼을 거두는 장치 — 「성흔」과 「낙인」 🔧
양쪽 진영 모두의 죽음을 거두려면 장치가 둘 필요하다.
| 장치 | 누가 받나 | 겉의 의미 | 진실 |
|---|---|---|---|
| **성흔(聖痕)** | 성전 연합의 병사·용병·기사 | 성전의 축복, 명예의 표식 | 혼을 묶는 주술 각인 |
| **낙인(烙印)** | 낙인 진영의 포로, 점령지 주민, "악마 숭배자" 판결을 받은 자 | 이단의 처벌 표식 | **성흔과 똑같은 주술 각인** |
- 축복과 처벌이 사실은 **같은 것의 앞면과 뒷면**이다. 이를 알아채는 것이 진실의 큰 조각이다.
- **대학살의 밤**: 30년째 되는 밤, 대륙의 모든 성흔과 낙인이 동시에 불타오른다. 각인이 없는 사람들도 그 밤에 일어나는 혼의 폭풍에 휘말린다.

### 30년 전쟁의 흐름 🔧
| 시기 | 주인공 나이(시작 10세 기준) | 전쟁 |
|---|---|---|
| 1~5년 | 10~15세 | "악마 출현" 소문, 국경 분쟁 |
| 6~12년 | 16~22세 | 성전 선포, 두 진영이 갈라짐 |
| 13~22년 | 23~32세 | 대륙 전면전 |
| 23~29년 | 33~39세 | 소모전, 기근, 역병. 진실이 새어 나오기 시작 |
| 30년 | 40세 | **대학살의 밤** |

## 3. 죽음과 되감기 규칙 (상세) ✅ 방향, 🔧 세부
| 규칙 | 내용 |
|---|---|
| 목숨 | 3개 = 세 번의 삶(세계의 9·10·11번째 삶) |
| 되감기 | 어디서 죽든 시간이 "요람의 날"로 되감기고 목숨이 1개 줄어든다 |
| 대학살의 밤 | 첫째·둘째 삶에서는 피할 수 없는 확정 사건이다. 셋째 삶의 대학살의 밤은 **최종 결전**이다 |
| 실마리 ① 혼의 해방 | 혼이 유물로 빨려 들어가는 흐름을 **끝까지 지켜보며** 죽어야 얻는다 (의식 장소에 가까이 가야 함) |
| 실마리 ② 진짜 이름 | 대악마가 깨어나는 순간 그 **목소리를 들으며** 죽어야 얻는다 (대악마의 첫 유혹을 거절하는 것이 조건) |
| 순서 | 정해져 있지 않다. 단, **같은 방식으로 두 번 죽으면 같은 실마리만 얻는다** |
| 헛된 죽음 | 대학살의 밤이 아닌 곳에서 죽으면 되감기 + 목숨 −1 + **악몽의 조각** 1개 |
| 악몽의 조각 | 3개를 모으면 실마리 하나를 대신할 수 있다. 조각 하나마다 혼이 깎여 결말의 대가(4절)가 한 단계 무거워진다 |
| 첫 경고 | 옛 신은 각지에 봉인되어 있어 직접 오지 못한다. 대신 **유년기의 꿈**으로 마지막 메아리를 보낸다: "너의 죽음은 세 번. 둘은 검은 새벽에 바쳐라" |
| 셋째 삶에서 죽으면 | 더 이상 되감기지 않는다. 그 자리에서 엔딩 (대부분 배드) |
| 저장 | 같은 삶 안에서만 저장·불러오기. 시대가 바뀔 때마다 자동 저장. 죽는 순간 그 삶의 저장은 모두 잠긴다 |

## 4. 혼을 쓴 대가 — 「잊힌 영웅」 ✅
주술을 쓰거나 인간의 혼을 이용해 성장했다면, 대악마를 쓰러뜨린 뒤 대가를 치른다.
| 혼 사용량 | 대가 |
|---|---|
| 없음 | 대가 없음. 온전한 해피엔딩 |
| 적음 | 기억 일부와 감정 하나(기쁨, 슬픔, 사랑 중 하나)를 잃는다 |
| 보통 | 가장 가까운 사람들이 주인공을 잊는다 |
| 많음 | 대악마를 쓰러뜨린 순간 **세상 모든 사람의 기억에서 주인공이 지워진다** |
| 악몽의 조각 사용 | 위 단계를 한 단계씩 무겁게 만든다 |
- 디렉터가 원한 결말의 감정 **"허탈함, 허무함, 그리고 기쁨"**의 중심 장치. 세계는 살았고 그것은 기쁘지만, 그 세계에 주인공의 자리는 없다.

## 5. 대악마의 유혹 ✅
- 세 번의 삶 내내 꿈속에서 조금씩 속삭인다. 삶이 거듭될수록 목소리가 또렷해진다.
- 둘째 삶의 대학살의 밤: 첫 정식 유혹. 거절해야 실마리 ②(진짜 이름)를 얻는다.
- 최종 결전: "함께 세계를 정복하자." 플레이어는 **주관식으로 답한다.**
- 받아들이면 **타락 엔딩**(잔혹도 9단계): 주인공이 대악마의 그릇이 되어 자기 손으로 세계를 지배하고 망친다. 출신마다 타락의 모습이 다르다.

## 6. 두 번째·세 번째 삶 ✅
| 규칙 | 내용 |
|---|---|
| 이어지는 것 | **기억뿐** |
| 다시 시작하는 것 | 몸, 능력, 서클, 숙련도, 재산, 지위, 관계, 깨달음 전부 |
| 사건 | 아는 사건이라도 건너뛸 수 없다. 대신 **더 나은 선택**을 할 수 있다 |
| 깨달음 | 옛 신을 다시 찾아가 다시 얻어야 한다. 다만 어디에 봉인되어 있는지, 어떤 시험인지 기억하므로 **더 빨리** 얻을 수 있다 |
| 주변의 반응 | 아이가 알 수 없는 것을 아는 주인공을 사람들이 이상하게 여긴다: 신동, 예언자, 마녀, 미친 아이. 출신에 따라 반응이 다르다 |
| 대악마 | 주인공이 기억한다는 것을 대악마도 안다. 삶이 거듭될수록 대악마의 방해가 교묘해진다 |

## 7. 옛 신의 봉인 ✅
- 옛 신 10명은 대륙 곳곳(두 제국, 아홉 왕국, 큰 세력의 땅, 바다, 산, 폐허)에 흩어져 봉인되어 있다.
- **사제를 포함한 모든 출신이 직접 찾아가야 한다.**
- 해피엔딩에는 7명 이상의 도움과 깨달음이 필요하다.
- ❓ 10명의 이름, 성격, 봉인 장소, 시험 내용 (다음 세계관 회의 안건)
