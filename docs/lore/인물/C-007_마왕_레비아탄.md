## 2. 겉모습 (아트용 3줄)
- 실루엣: 숙주의 **고개가 늘 옆 사람 쪽으로 반쯤 돌아가 있다.** 정면을 보지 않는 몸.
- 색: 주색이 없다. 숙주의 옷 색이 **옆에 선 사람의 색 쪽으로 조금씩 물든다**(셀 셰이딩 팔레트가 장면마다 옆 인물을 따라 바뀐다 — 판별 단서, 🔧).
- 소품: 숙주의 손에는 늘 **남의 물건**이 있다. 빌린 장갑, 주운 반지, 맡아 둔 편지.
- 숨 버릇(F-C11, 🔧): 남의 손이나 물건을 볼 때만 **콧숨을 짧게 두 번** 쉰다.

## 3. 마음
| 칸 | 내용 |
|---|---|
| 겉으로 원하는 것 | (숙주의 입으로) "공정함. 누가 무엇을 가졌는지 모두가 똑똑히 알게 하는 것." |
| 진짜 원하는 것 | **누군가 자기를 부러워해 주는 것.** 그리고 더 깊이: 비교하지 않아도 되는 **자기 것 하나** |
| 두려움 | 누군가 그를 **정면으로** 보는 것. 비교할 상대 없이 혼자 보이면 그는 아무것도 아니다 |
| 비밀 | 그는 두 제국 모두의 궁정에 말을 넣는다. 제2제국 황제(C-010)의 영토 욕심도, 제1제국 왕국들의 동맹 다툼도 그가 키웠다. 그는 **어느 쪽이 이기든 상관없다.** 전쟁이 길어지기만 하면 된다 |
| 하는 거짓말 | 비교로 된 칭찬: "폐하의 군대는 저쪽보다 강합니다." — 숫자는 맞다. 거짓은 "그러니 지금 치십시오"라는, 말하지 않은 뒷말이다 |
| 스스로에게 하는 거짓말 | "나는 아무것도 원하지 않는다. 비교할 뿐이다." |
| 믿는 반쪽 진실 | **맞는 쪽:** 사람은 남이 가진 것을 보고서야 자기가 원하는 것을 안다. / **틀린 쪽:** 그러니 원하는 것은 모두 남의 것이다 |
| 선의 · 이용 · 동기 | 선의(이해할 수 있는 마음): 그는 누구보다 **정확하게** 사람의 값을 본다. 그의 칭찬은 늘 사실이다. 그는 무시당한 사람의 숨은 재능을 가장 먼저 알아본다. / 이용: 그 정확한 눈으로 두 사람을 나란히 세워 서로 미워하게 한다. / 동기: **원한 · 몫** |

## 11. AI 주관식 대화 메모
- 절대 하지 않는 말: 비교 없는 칭찬. 거짓 숫자(그의 숫자는 늘 맞다).
- 의도 매칭 주의: "칭찬"과 "모욕"을 둘 다 **비교로 되돌린다**("나보다 저 사람한테 하세요"). "동정"은 그를 흔든다(동정은 비교가 아니다) → 반응 문장 따로.
- 4계열: **믿는다** → 비교 칭찬이 늘어난다. **따진다** → 숫자로 답한다. 숫자는 맞다. **떠본다** → "당신은 뭘 가졌어요?"로 떠보면 대답하지 못한다(단서). **숨긴다** → 숨긴 물건을 갖고 싶어 한다. 숨긴 것이 물건이면 위험하다.
- 확신이 낮을 때: "그 말, 저 사람이 했으면 더 그럴듯했을 텐데요."
