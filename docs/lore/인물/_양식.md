## 0. 카드 쓰는 규칙 (10줄)
1. **모든 인물은 선의와 이용을 함께 가진다.** 순수한 악인도, 순수한 선인도 없다. 대악마도 "원하는 것"이 사람이 이해할 수 있어야 한다.
2. **정보는 막지 않는다.** 이 인물은 신분과 상관없이 아는 것을 말해 준다. 어려운 이유는 그 말이 **반쪽**이기 때문이다(`docs/11` 5절).
3. 모든 인물은 **믿는 반쪽 진실** 하나를 가진다. "맞는 쪽"과 "틀린 쪽"을 반드시 나눠 적는다.
4. **묶임 상태**(명부·계약·서원·없음)를 반드시 적는다. 묶인 사람의 눈은 대악마의 눈이다(R10). 대화 장면을 짤 때 가장 먼저 보는 칸이다.
5. **NPC는 같은 말을 반복하지 않는다.** 한 삶 안에서 같은 대답을 두 번 하지 않는다. 대신 "태도 변화 규칙"으로 관계·시대·사건에 따라 말이 바뀐다.
6. 예외는 하나: **세 삶 반복 대사**. 같은 사건에서 같은 인물이 세 삶 모두 똑같이 하는 한 줄(`docs/11` 4절 7). 주인공의 기억 때문에 뜻이 달라진다. 카드마다 최대 1줄.
7. 대사마다 **현지화 맥락 메모**를 단다: 화자→청자 · 관계 · 감정 · 복선 여부(`docs/06`).
8. 인물의 **성격과 가치는 출신을 넘어 고정**하고, 처한 상황만 바꾼다(의심 설계 v1.1 2절 원칙).
9. 다른 작품의 이름·설정·인물·대사를 가져오지 않는다. 실제 역사·신화의 이름은 공공 전승일 때만 쓰고, 해석은 우리가 새로 한다.
10. 수위는 15~18세. 잔혹한 일은 "결과와 표정"으로 쓰고 "행위의 세부"는 쓰지 않는다.
11. **사실 확인 (v1.1)**: "사실로는 속이지 않는다"는 인물(대악마 C-005, 마왕 C-006~C-008)의 대사는 새로 쓸 때마다 **그 대사가 그 순간 사실인가**를 확인 칸에 적는다. 미래의 일은 사실이 아니다("올해 서명한다" ✗ → "지난 두 번, 올해 서명했다" ✓). 조건이 필요한 사실은 `when` 식으로 붙인다(5절).
12. **마왕 겹치기 (v1.1)**: 마왕이 든 사람은 **숙주 카드가 먼저**다. 마왕 카드는 숙주 위에 ① 말버릇 하나 ② 숨 버릇 하나 ③ 보조 표지 하나만 덧씌운다. 신뢰 수치(`trust`)는 숙주 것을 그대로 쓴다. 마왕은 삶을 기억하지 못하므로 **세 삶 반복 대사를 두지 않는다**(카드에 "없음" 칸도 쓰지 않는다).
13. **숨는 자리 판정에 끼어들지 않기 (v1.1)**: 마왕의 성격·취향은 R9-보 판정식(신뢰 최고 후보 · 안 간 장소)을 바꾸지 않는다. "숨은 둘이 **누구**인가"는 출신별 데이터(부록 D)가 정한다. 카드에는 "그 자리에 들었을 때 어떻게 숨는가"만 쓴다.
14. **공정한 단서는 저사양에서도 남아야 한다 (v1.1)**: 해피 경로 판정에 쓰는 단서는 **소리(숨)와 말버릇**이 주 단서다. 그림자·색 변화·후처리 효과는 보조 단서로만. 숨 소리에는 자막 표기를 함께 정한다(예: `[숨이 반 박자 멈춘다]`).
15. **주인공 이름**: 플레이어가 정한 이름은 녹음할 수 없다. 이름을 부르는 대사는 자막에만 이름을 쓰고, 목소리는 이름 자리에서 끊긴다.
16. 🔧 **요람의 날 이전의 일 (설정 관리자 확정 전, ❓ Q-116)**: 30년 연표가 시작되기 전에 한 서원·꿈·사건(C-009 17~18세, C-014 20세, C-015 30년 전 제자)은 "**서원이 닿는 곳은 지금의 상태로 정한다**"는 원칙을 따른다고 가정하고 쓴다.

## 2. 칸마다 쓰는 요령
| 칸 | 요령 | 나쁜 예 → 좋은 예 |
|---|---|---|
| 한 줄 | 인물의 모순을 한 문장에 | "나쁜 황제" → "멸망을 막으려 멸망을 부르는 황제" |
| 실루엣 | 그림자만으로 구분되게. 셀 셰이딩은 외곽선이 굵으니 **모양이 단순할수록** 좋다 | "멋진 갑옷" → "어깨가 좁고 망토 깃만 높이 선 세로로 긴 몸" |
| 색 | 주색은 인물마다 겹치지 않게(목록 파일의 색 표 확인) | |
| 믿는 반쪽 진실 | 맞는 쪽은 **진짜 사실**이어야 한다. 틀린 쪽은 **해석**이다 | |
| 하는 거짓말 vs 스스로에게 하는 거짓말 | 앞은 알고 하는 말, 뒤는 모르고(또는 모른 척) 믿는 말 | |
| 예시 대사 | 5줄은 **서로 다른 감정**으로. 인사·위협·고백·농담·침묵 같은 식 | |
| 맥락 메모 | 영어·일본어 번역가가 이 메모만 보고 존댓말·격식을 고를 수 있게 | |
| 세 삶 반복 대사 | 같은 말이 삶마다 다르게 들려야 한다. 주인공의 기억이 뜻을 바꾼다 | |
| 태도 변화 규칙 | "신뢰가 오르면 말이 길어진다"처럼 **눈에 보이는 변화**로 | |
| 죽음/생존 | 대학살의 밤, 해방 뒤, 결전 뒤를 나눠서. 묶인 인물은 해방 전까지 굳는다(R10) | |
| 절대 하지 않는 말 | AI가 아는 척하거나 규칙을 깨지 않게. 특히 **진짜 이름을 소리로 말하는 일은 누구도 할 수 없다**(R2) | |

## 3. 대사 ID 규칙
- 예시 대사: `char.c001.s01` ~ `s05`
- 세 삶 반복 대사: `char.c001.echo`
- 실제 장면 대사는 장면 ID를 따른다: `scene.<출신>.<장면>.<인물>_<번호>` (예: `scene.o01.y22_library.c012_03`). 인물 카드에는 적지 않는다.

## 4. 인물 ID 범위 (🔧 제안)
| 범위 | 쓰임 |
|---|---|
| C-001 ~ C-099 | 공통 핵심 인물 (어느 출신에서나 만나는 사람·존재) |
| C-110 ~ C-309 | 출신별 인물. 공식 = 100 + 출신번호 × 10 + 순번(0~9). 예: O01 → C-110~C-119, O10 → C-200~C-209, O20 → C-300~C-309 |
| O21 이후 | 출신을 늘릴 때 다시 정한다 (❓ Q-101) |
- ⚠️ **번호 혼동 주의**: 인물 ID는 **세 자리**(C-001), 공통 결말은 **두 자리**(C-01 「역봉인」). 자동 검사에서 헷갈릴 수 있다(❓ Q-101).
- 같은 사람이 두 출신에 나오면(예: O07 후원 소녀 = O12 주인공) ID는 **하나만** 쓰고, 두 출신 칸에 함께 적는다.

## 5. 대화 데이터로 옮기는 규칙 (v1.1 · `docs/12` 초안 표기에 맞춤)
> `docs/12`는 아직 초안이다. 아래에서 🔧 표시한 것은 **`docs/12`에 없는 것을 이 양식이 새로 제안**하는 것이다(programmer·qa 검토 필요, ❓ Q-119).

### 5-1. 신뢰 단계 기준값
`docs/12` 3-1: `trust`는 인물별 정수, 범위 **-3 ~ 3**, 범위 `life`(되감기면 0).
| 카드 낱말 | 식 |
|---|---|
| 신뢰 낮음 | `trust(C-xxx) <= -1` |
| 신뢰 보통 | `trust(C-xxx) >= 0 && trust(C-xxx) <= 1` |
| 신뢰 높음 | `trust(C-xxx) >= 2` |
| 신뢰 최고(카드에 "최고"라고 쓴 곳) | `trust(C-xxx) == 3` |
- 삶이 시작되면 모든 인물은 0(보통)에서 시작한다. 카드 본문의 "신뢰 낮음/보통/높음"은 이 표의 뜻이다.

### 5-2. 의도 이름
- `docs/12` 3-2에 있는 공통 의도 id만 그대로 쓴다: `truth` `lie` `deflect` `threaten` `bargain` `ask_back` `accuse`.
- 그 밖의 의도는 이름 뒤에 **＊**를 붙여 "공통 의도 사전 후보"로 표시하고 T-108(의도 60개 목록)에 올린다. 카드에서 쓰는 후보와 제안 계열:

| 후보 id | 뜻 | 제안 계열 | 쓰는 카드 |
|---|---|---|---|
| `pity`＊ | 동정 | 믿는다 | C-001 C-003 C-005 C-007 C-010 C-013 |
| `insult`＊ | 모욕(신성모독 포함) | 따진다 | C-001 C-007 C-009 |
| `appeal_faith`＊ | 신앙에 호소 | 믿는다 | C-001 C-006 C-009 C-011 C-014 |
| `flatter`＊ | 칭찬·아첨 | 떠본다 | C-006 C-007 C-015 |
| `rank`＊ | 신분 내세우기 | 따진다 | C-010 C-015 |
| `help_request`＊ | 도움 요청 | 믿는다 | C-008 |
| `give_up`＊ | 포기·진실을 거부("그만할래", "모르겠어") | 숨긴다 | C-008 |
| `joke`＊ | 농담 | 떠본다 | C-004 C-011 |
| `question`＊ | 그냥 묻기(정보 요청) | 떠본다 | C-004 C-013 |
- **장면 전용 의도**(`docs/08` 0절 3): 그 장면에서만 의미 있는 말. 접두어 `scene:`. 예: `scene:name_god`(옛 신 이름 대기), `scene:name_lucifer`(마왕의 이름 부르기).
- **빈 입력은 의도가 아니다.** 아무것도 쓰지 않거나 "…"만 쓴 입력은 매칭 모델을 거치지 않고 **게임 규칙**으로 받는다: 🔧 `input.empty`(bool, 이번 입력에만). C-004 같은 인물의 해석표에서 `when: "input.empty"` 줄로 받는다.

### 5-3. 말이 아닌 행동 — 행동 태그 🔧
- 주관식 매칭으로 잡히지 않는 행동(정면으로 보기, 물건 살피기, 얼굴 먼저 보여 주기)은 **행동 태그**로 쓴다.
- 모양: 플래그 장부(`flags.json`)에 `did.<인물>_<행동>` 이름의 bool, 범위 `life`. 게임 조작(시선·조사·몸짓 버튼)이 켠다. 장면 식에서는 `did.c007_look_direct`처럼 이름 그대로 쓴다(`docs/12` 3-5 "플래그 이름 + 비교"만 쓰는 규칙을 지킨다).
- 카드에서 쓰는 행동 태그는 각 카드 0절에 모아 둔다. 목록은 `_목록.md` 4절.

### 5-4. 셈판 🔧
- "세 번 따지면", "질문은 한 번만", "대화 셋에 한 번" 같은 조건은 **셈판**으로 쓴다.
- 모양: `cnt.<인물>_<무엇>` int, 범위 `life`(또는 `scene` 🔧 — 장면이 끝나면 0. `docs/12`에 없는 범위). 효과는 `set cnt.c013_ask = cnt.c013_ask + 1` 대신 `docs/12` 효과 식에 맞춰 🔧 `cnt.c013_ask += 1`.

### 5-5. 반복 허용 표시 🔧
- `docs/12` 3-4의 `repeatAcrossLives: true` = 세 삶 반복 대사(`char.cxxx.echo`). 삶마다 한 번.
- **한 삶 안에서 일부러 되풀이하는 줄**(거짓말할 때만 같은 말, 흔들릴 때 되풀이, 같은 대사를 두 사람에게)은 🔧 `allowRepeat` 표시를 단다: `{ "line": "char.c003.s03", "allowRepeat": { "max": 2, "why": "거짓말일 때만 되풀이하는 버릇" } }`. 이 표시가 없으면 반복 금지 검사가 오류로 잡는다(`docs/12` 5절).
