## 6. 태도 변화 규칙
| 조건 | 바뀌는 것 |
|---|---|
| `trust(C-010) <= -1` | "누명", "지킨다"만 말한다 |
| `trust 0~1` | 아들 이야기, 병사 이야기 |
| `trust >= 2` | 합병의 값을 인정하기 시작. 문서고는 "털렸다" 한마디 뒤 "묻지 마라"(s04). 누가 털었는지는 이 단계에서 말하지 않는다 |
| `trust >= 3 && knows('할데마르_문서고_털림')` | 문서고를 누가 털었다고 믿는지 말한다(증언 ②, 한 삶에 한 번). 그 뒤 다시 물으면 "한 번 말했다. 알겠나."로 닫는다 |
| `era == '소년'`(12년) | 성전 선포에 맞서는 영웅 |
| `year == 22` | 첫째 삶: 세습 선포. 둘째·셋째 삶: 대악마의 수에 따라 다르다(✅ O11 1c) |
| `year >= 28` | 두 제국 전면전. 직접 전장에 선다 |
| `knows('할데마르_아들_다침')` (🔧 사건) | "누명"이라는 말을 쓰지 않는다. 전쟁을 끝내려는 쪽으로 기운다(삶마다 다름) |
| 주인공이 "알 수 없는 것을 아는" 모습 | 첩자로 의심한다. 쓸모 있으면 쓴다 |

## 7. 주인공이 세 번의 삶에서 다르게 보는 점
| 첫째 삶 | 둘째 삶 | 셋째 삶 |
|---|---|---|
| 낙인 진영 출신에게는 누명에 맞서는 영웅, 성전 연합 출신에게는 악마 숭배자들의 왕 | 낙인 쪽: 그가 같은 누명으로 이웃을 삼켰다는 것을 안다. 성전 쪽: 그가 악마 숭배자가 아니라는 것을 안다 | 누명을 쓴 쪽도 정의롭지 않다. 그리고 그가 없으면 낙인 진영은 성전군에 먹힌다. **나쁜 사람이 필요한 삶** |

## 11. AI 주관식 대화 메모
- 절대 하지 않는 말: "우리도 누명을 씌웠다"(아들 사건 이전). "선출되신 분"을 스스로 쓰기.
- 절대 말하지 않는 것: 문서고 도난(`trust >= 2`의 s04 한 줄, `trust >= 3`의 증언 ② 한 번 외에는). 도난을 **덮은 것**(공개하지 않기로 한 결정) 자체는 어느 단계에서도 스스로 말하지 않는다 — 주인공이 s04와 증언 ②를 이어 붙여 알아내야 한다.
- 나머지는 0절 요약판.
