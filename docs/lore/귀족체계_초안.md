# 귀족 체계 초안 — 왕국과 제국

> 상태: ✅ 디렉터 확정 뼈대 + 🔧 자비스 세부안
> 디렉터: 왕국은 왕과 50개 귀족 가문(계급이 각각 다름, 공작은 반드시 2명), 제국은 황제와 100개 귀족 가문(왕국과 다른 계급 체계). 모든 왕가·황가·귀족 가문마다 고유 검술과 용병술.

## 1. 왕국 — 땅과 피의 서열 (봉건 세습제)
땅을 받고 충성을 맹세하는 전통적인 봉건 질서. 작위는 피로 이어진다.

| 작위 | 수 | 의미 |
|---|---|---|
| 왕가 | 1 | 왕국의 주인. **왕가 비전 검술**을 가진다 |
| 공작 | **2** ✅ | 왕국의 양 날개. 왕위 계승권이 있는 가문. 서로 숙적 |
| 후작 | 4 | 국경(변경)을 지키는 가문 |
| 백작 | 8 | 큰 영지와 성을 가진 가문 |
| 자작 | 12 | 백작을 보좌하거나 도시를 다스리는 가문 |
| 남작 | 24 | 작은 영지의 가문 |
| **합계** | **50** | |

## 2. 제국 — 십주(十柱) 체계 (직분 서열제) 🔧
제국은 땅이 아니라 **직분**으로 서열을 매긴다. 건국 때 황제를 받친 **열 개의 기둥(주가, 柱家)**과 그 아래 **아홉 개씩의 지가(支家)**로 이루어진다. 작위는 세습되지만, 직분을 잃으면 가문도 기둥에서 떨어진다.

| 계급 | 수 | 의미 |
|---|---|---|
| 황가 | 1 | 제국의 주인. **황제검**을 가진다 |
| 주가(柱家) | 10 | 열 기둥. 각자 하나의 직분을 맡는다 |
| 상지가(上支家) | 30 | 기둥마다 3 |
| 중지가(中支家) | 30 | 기둥마다 3 |
| 하지가(下支家) | 30 | 기둥마다 3 |
| **합계** | **100** | |

**열 기둥의 직분 (가제)**
| 기둥 | 직분 | 검술·용병술 성향 |
|---|---|---|
| 검(劍)의 기둥 | 황제 친위·결투 재판 | 결투 검술의 정점 |
| 방패(盾)의 기둥 | 국경 방어·요새 | 방패 대열, 공성 방어 |
| 창(槍)의 기둥 | 정규군 보병 | 장창 밀집 대열 |
| 말(馬)의 기둥 | 기병대 | 기마 검술, 돌격 |
| 저울(秤)의 기둥 | 재정·세금·**은화 주조** | 호위 검술, 용병 고용술 |
| 펜(筆)의 기둥 | 법·기록·역사 편찬 | 의전 검술(약함) — 대신 정보전 |
| 등불(燈)의 기둥 | 교단·성전 축복 | 성기사 검술, **성흔 수여** |
| 사슬(鎖)의 기둥 | 감옥·처형·이단 심문 | 제압·포박 검술 |
| 종(鐘)의 기둥 | 전령·첩보 | 암살 단검술 |
| **열쇠(鑰)의 기둥** | 황궁 깊은 곳의 문지기 (공식 직분은 "보물고 관리") | 기록에 없는 검술 — **비밀 조직의 핵심** |

- 🔧 숨은 진실: 열 기둥은 원래 **옛 신 열 명을 섬기던 신관 가문**이었다. 제국은 옛 신 숭배를 지우고 직분으로 바꿨다. 기둥마다 한 명의 옛 신과 연결된 유물이나 기록이 숨어 있다 → **7명 이상의 옛 신을 찾는 여정**과 연결된다.
- 등불의 기둥이 성흔을 나눠 주고, 저울의 기둥이 은화를 찍는다. 대학살 장치의 손과 발이다. 열쇠의 기둥은 유물의 문지기다.
