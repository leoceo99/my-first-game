# 진실: 「되풀이되는 세계」 v0.2 (초안)

> 상태: **초안 — 디렉터와 함께 다듬는 중.** 확정 전까지 다른 문서에서 "정답"으로 쓰지 않습니다.
> 디렉터 결정: 진실은 후보 B. 단 "어지간한 영화나 드라마보다 짜임새 있게" 더 손볼 것.
> 이 문서는 플레이어가 **절대 한 번에 보지 못하는** 전체 진실입니다.

## 1. 한 문장
**세계는 이미 여러 번 끝났고, 누군가 매번 처음으로 되감고 있다. 그 되감기는 구원이 아니라, 세계를 갉아먹는 의식이다.**

## 2. 진실의 5겹 구조 (드러나는 순서)

| 겹 | 플레이어가 알게 되는 것 | 주로 드러나는 곳 |
|---|---|---|
| 1. 이상한 일상 | 대륙 사람 대부분이 같은 악몽("검은 새벽")을 꾼다. 처음 보는 사람이 낯익다. 사람들은 이를 미신으로 넘긴다 | 모든 출신의 초반 |
| 2. 역사의 공백 | 역사책에 수백 년 단위의 공백이 주기적으로 있다. 땅속 유적은 지금보다 앞선 문명의 것이다. 제국은 "천년 제국"을 자칭하지만 건국 기록이 맞지 않는다 | 학자·성직자·귀족 루트, 서브 스토리 |
| 3. 되감기 | 세계는 멸망할 때마다 처음으로 되돌려진다. 되돌리는 장치(또는 존재)가 있고, 제국의 가장 깊은 곳이 그것과 연결되어 있다 | 메인 스토리 중반 |
| 4. 대가 | 되감을 때마다 무언가가 소모된다. 마법·연금술·주술의 힘은 사실 **이전 회차들의 잔해**(기억, 삶, 영혼의 조각)를 태워 얻는 것이다. 힘을 쓸수록 과거 회차의 누군가가 영원히 사라진다 | 메인 후반, 히든 |
| 5. 진짜 목적 | (디렉터와 결정) 되감기는 세계를 구하려는 것이 아니라 **특정 결과**를 얻을 때까지 반복하는 실험·사육·형벌 중 하나다. 그리고 멸망("검은 새벽")의 원인은 외부가 아니라 **되감기 그 자체**일 수 있다 | 최종 진실, 히든 엔딩 |

## 3. 게임 시스템과 진실의 연결 (이 구조의 핵심 장점)

| 시스템 | 진실로 설명되는 이유 |
|---|---|
| **목숨 3번** | 주인공은 작은 되감기를 "기억하는" 이상 존재다. 죽으면 되감기에 끌려 돌아오지만, 3번을 넘기면 자기 자신이 연료로 소모된다 |
| **새 게임 = 새 회차** | 플레이어가 새 캐릭터로 다시 시작하면, 세계는 다음 회차다. 이전 플레이의 엔딩이 전설·유적·유령·데자뷰로 흔적을 남긴다 (예: 이전 플레이에서 왕이 된 캐릭터의 동상이 폐허로 발견됨) |
| **진실을 거부해도 끌려감** | 디렉터 결정: 진실을 외면해도 결국 파헤치게 된다. 되감기는 "이상 존재"를 자기에게 끌어당기므로, 주인공이 피할수록 사건이 주인공 쪽으로 몰려온다 |
| **자연사 없음** | 디렉터 결정: 자연스러운 죽음은 없다. 회차는 늘 주인공의 생애 안에서 끝(멸망 또는 엔딩)에 도달하도록 설계된다 |
| **NPC가 계속 달라짐** | NPC도 희미하게 이전 회차를 기억해, 플레이 횟수가 쌓일수록 주인공에게 다르게 반응한다 |
| **해피엔딩이 단 하나** | 되감기의 고리를 끊거나 비트는 길은 출신마다 하나뿐이다 |
| **시리즈** | 다른 시대 = 다른 회차, 또는 고리가 끊긴 뒤의 세계 (2편 이후 결정) |

## 4. 짜임새를 위한 설계 원칙
1. **전체 연표를 먼저 완성**: 0회차부터 현재 회차까지 무슨 일이 있었는지 작가팀 내부 연표를 완전히 만든 뒤 장면을 쓴다.
2. **모든 이상 현상에는 이유가 있다**: 악몽, 데자뷰, 역사의 공백, 낯선 유적 하나하나가 연표의 어떤 사건과 연결되는지 복선 장부에 기록한다.
3. **악역에게도 납득할 이유**: 되감기를 유지하는 쪽은 나름의 정당한 이유(예: 되감지 않으면 더 끔찍한 것이 온다고 믿음)를 가진다. 플레이어가 "나라도 그랬을 것"이라고 느끼게 만든다.
4. **진실은 공정하게**: 5겹의 진실은 모두 1겹째부터 복선이 깔려 있어야 한다.
5. **여러 시선**: 같은 진실 조각을 노예, 귀족, 성직자, 용병이 각자 다른 의미로 받아들인다.

## 5. 디렉터와 함께 정할 질문
1. 되감는 것은 **장치**(고대 유물), **존재**(신 또는 괴물), **사람**(황제, 비밀 결사) 중 무엇인가? 섞어도 된다.
2. 되감기의 진짜 목적은 **실험**(완벽한 결과를 찾음), **사육**(무언가를 기르고 거둠), **형벌**(누군가가 벌을 받고 있음), **사랑**(잃은 누군가를 되찾으려 함) 중 무엇에 가까운가?
3. 지금이 몇 번째 회차인가? (예: 7번째)
4. 주인공이 이상 존재가 된 이유는? 우연, 혈통, 이전 회차의 자신이 남긴 것 중 무엇인가?
5. 해피엔딩에서 고리를 **끊는가**, **바꾸는가**, **넘겨받는가**?
6. 마법·연금술·주술이 "이전 회차의 잔해를 태운다"는 설정에서, 세 가지는 각각 무엇을 태우는가? (예: 마법은 기억, 연금술은 육체, 주술은 감정)
