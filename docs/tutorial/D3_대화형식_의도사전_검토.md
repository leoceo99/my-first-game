## 0. 핵심 발견 3줄
1. 두 문서는 큰 틀(의도 매칭·계열 기본+예외·문장 표 분리)은 타당하지만, **작가가 실제로 장면을 쓰려면 막히는 곳이 필수 12건**이다(해석표에 계열 기본 반응 칸 없음, 장면 전용 의도 선언 없음, 4계열 결과를 적는 칸 없음, 겉말·속뜻 판정 자리 없음, 조건식 규칙 모순 등).
2. **4계열 뜻풀이가 60개 의도와 의심 설계 사이에서 어긋난다.** 인사·감사·농담·작별 같은 일상 말이 "믿는다 성공"으로 기록될 수 있고, 뇌물·아첨·굴복·포기는 뜻풀이에 안 맞는다. 계열 수는 그대로 두고 뜻을 넓히고 일상 의도 4개를 기록에서 빼는 안을 냈다.
3. 인물 카드가 쓰는 의도 이름 18줄을 조사해 **12가지가 공통 사전과 어긋났다**(이름만 다름 3, 이름·계열이 모두 다름 1, 사전에 아예 없음 3, 뜻이 쪼개지거나 묶인 것 3, 장면 전용·태그 2 등. "시기"·"회유"·"큰 소리"처럼 말로만 적힌 것 포함). 카드 이름과 사전을 잇는 별칭표를 만들었다.

## 2. 인물 카드에만 있는 의도 이름 전수 조사
