## 2. 핵심 루프

```
[짧은 루프 · 분 단위]  탐험 → 만남/대화(선택지) → 의뢰·전투·거래 → 보상·관계 변화
[중간 루프 · 시간 단위] 재능·기술 성장 → 신분/재산/세력 확대 → 더 큰 사건에 접근
[긴 루프 · 플레이 전체] 진실의 단서 수집 → 세계의 비밀에 다가감 → 엔딩 (출신마다 해피엔딩 1개)
[반복 플레이]          다른 출신으로 재시작 → 다른 시점의 진실 조각 → 전체 진실 완성
```

### 오리진(출신 원형) 개념 — ❓확인 필요
가능한 조합은 수만 가지라, 스토리는 **오리진** 단위로 짭니다.
"신분 + 직업" 조합을 12~20개의 오리진으로 묶고, **오리진마다 해피엔딩 1개 + 배드/열린 엔딩 여러 개**를 둡니다.
나이·성별·재력·재능·특징은 같은 오리진 안에서 대사, 기회, 가능한 엔딩을 바꿉니다.

## 4. 주요 시스템

### 4-1. 전투 ✅ 직접 전투 + 부대 지휘
- **직접 전투**: 무기별 공격 방향(상·하·좌·우 베기, 찌르기), 막기·흘리기, 체력(스태미나), 부위별 피해, 활·석궁, 기마전
- **부대 지휘**: 대형, 진격·후퇴·돌격·사격 명령, 사기(士氣), 지형·날씨 영향, 공성전
- **규모 성장**: 혼자 → 동료 몇 명 → 용병단·기사단 → 군대(영지전)
- **마법·연금술·주술**: 전투와 생활 모두에 영향. 체계는 사용자와 함께 설계 (02 문서 참고)

### 4-2. 목숨 3번 ✅ (세부 ❓)
- 한 인생에 **목숨 3개**. 죽으면 마지막 저장 지점으로 돌아가고 목숨이 1개 줄어듦
- 3번째 죽음이면 그 인생은 끝 → 그 죽음은 엔딩 중 하나로 기록 → 새 인생으로 다시 시작
- ❓ 노화로 인한 자연사는 목숨 차감 없이 **후계자로 이어 하기**로 처리할지?

### 4-3. 인생·생활 ✅ (전부 포함)
- **시간과 나이**: 계절, 노화, 질병, 수명
- **가문과 후계**: 결혼, 자녀, 후계자로 이어 하기, 가문 평판
- **관계**: 친구·연인·라이벌·원수, 관계도, NPC도 자기 목적을 갖고 행동
- **경제**: 장사, 시세 변동, 무역로, 세금, 제작(대장·연금·약초)
- **영지 경영**: 영주 루트 — 세금, 건설, 징병, 반란, 외교
- **용병단 경영**: 용병 루트 — 계약, 급료, 장비, 단원 성장
- **평판·법**: 지역별 평판, 범죄와 처벌, 현상금

### 4-4. 스토리·선택지 ✅
- 메인 / 서브 / 히든 스토리, 진실의 단서를 모으는 **기록(일지) 시스템**
- **선택지**: 중요한 갈림길에서 7~10개 (❓일상 대화도 7~10개로 할지 — 피로감이 커서 일상 대화는 3~5개를 추천)
- **주관식 답변**: 장기 목표. AI가 플레이어가 직접 쓴 답변을 해석해 가장 가까운 분기로 연결하는 방식으로 검토 (인터넷 연결과 비용 발생 → 멀티플레이 단계에서 결정)
- **주인공 대사**: 플레이어가 고른 문장을 주인공이 실제로 말하는 방식 (주인공이 혼자 말하는 장면은 최소화)

### 4-5. 엔딩 규칙 ✅
- 오리진마다 **해피엔딩 1개**, 나머지는 배드엔딩 또는 열린 결말
- 배드엔딩 잔혹도 5단계 (02 문서 참고). 옵션의 표현 필터와 연동
- 엔딩 도감: 본 엔딩과 남은 엔딩 수를 표시해 반복 플레이 동기 부여

### 4-6. 튜토리얼 ✅
- 10분 분량. 움직이기, 시점 전환, 대화·선택지, 전투 기초, 저장, 진실의 첫 단서 하나
- 캐릭터 생성 전 "프롤로그"로 할지, 생성 직후 첫 사건으로 할지 ❓ → 추천: **고정된 짧은 프롤로그(세계의 진실을 암시) → 캐릭터 생성 → 오리진별 튜토리얼**

## 5. 화면·조작 (노트북 기준)

| 조작 | 키 |
|---|---|
| 이동 / 달리기 / 점프 | WASD / Shift / Space |
| 시점 전환 (1인칭↔3인칭) | V |
| 공격 / 막기 / 공격 방향 | 마우스 좌 / 우 / 마우스 이동 방향 |
| 상호작용 / 대화 | E |
| 부대 명령 | 숫자키 + F1~F4 (그룹), 명령 바퀴(Q 길게) |
| 일지·지도·인벤토리 | J / M / I |
| 빠른 저장 / 불러오기 | F5 / F9 |

모바일은 가상 조이스틱 + 버튼 배치를 별도 설계 (2순위).
