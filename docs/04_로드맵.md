# 04. 로드맵

> 기간 목표: 1~2년, 시간 날 때마다. 각 단계는 **"플레이 가능한 결과물 + 사용자 피드백"** 으로 끝납니다.
> 다음 단계는 사용자 승인 후 시작합니다.

## 0단계 — 초석 (지금)
- [x] 비전, 레퍼런스 조사, 기획서·세계관 틀·기술 설계 초안
- [x] 개발팀(역할별 에이전트) 구성, 자비스 운영 체계
- [ ] 사용자 승인: 기획 방향, 미정 사항(❓)
- [ ] 기술 검증 프로토타입: 3D 캐릭터 이동, **1·3인칭 전환**, 셀 셰이딩 1장면, 저장/불러오기 → 플레이 링크로 공유
- [ ] 성능 측정 (일반 노트북 기준), 기술 결정 확정
- [ ] 개발 기반: 프로젝트 골격, 자동 테스트, 아티팩트 배포, 다국어·대화 데이터 형식

## 1단계 — 세계관 회의 (사용자와 공동 작업)
- 진실의 방향, 마법·연금술·주술 체계, 제국·왕국 설정, 제목
- 오리진 목록 확정, 오리진별 메인 줄거리 개요와 엔딩 목록
- 결과물: `docs/lore/` 설정집, 스토리 바이블

## 2단계 — 버티컬 슬라이스: 10분 튜토리얼
- 프롤로그 + 캐릭터 생성(일부 항목) + 오리진 1개의 첫 10분
- 이동·시점 전환·대화 선택지·기초 전투·저장, 진실의 첫 단서
- 그래픽·사운드 방향 확정 (이 단계의 품질이 게임 전체의 기준이 됨)

## 3단계 — 핵심 시스템
- 직접 전투 완성, 목숨 3번, 시간·나이, 관계, 경제 기초
- 오리진 2~3개로 확장

## 4단계 — 지휘와 세력
- 부대 지휘, 용병단·영지 경영, 영지전·공성전

## 5단계 — 세계 확장
- 제국·왕국 지역, 메인·서브·히든 스토리 본격 제작, 엔딩 도감

## 6단계 — 다듬기와 출시 준비
- 모바일 조작, 다국어 검수, 최적화, 앱 포장, 출시

## 7단계 이후 — 멀티플레이, 주관식 답변, 시리즈 2편
